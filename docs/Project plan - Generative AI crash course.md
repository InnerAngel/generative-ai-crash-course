# 1. Project goal

Rather than sharing a large essay with generative AI topics, inspiration came from W3Schools or Codecademy to create a small interactive learning website. This should aid my coworkers and interns and teach them fundamentals about LLM, prompt-engineering, secure AI and agentic-AI. 

**The website is intended primarily as an introduction where it touches topics on:** 
1. How LLMs behave
2. Know how to provide useful context
3. Structure effective prompts
4. Recognize security and privacy risks
5. Verify outputs
6. Understand when an LLM or AI agent should and should not be trusted to act 

**Each topic should contain:** 
1. a short explanation
2. a visual or practical example
3. an interactive example where useful
4. a small multiple-choice quiz
5. navigation to the next topic
